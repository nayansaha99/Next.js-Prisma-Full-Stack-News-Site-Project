# News Website

This is a fully responsive news website built with HTML, CSS, Bootstrap, Next.js, Prisma, and MySQL.  
It features a user-friendly interface, smooth performance, and core functionalities such as login, registration, JWT authentication, profile management, commenting on news posts, and password recovery with OTP.

## Features

- Responsive design using HTML, CSS, and Bootstrap
- Frontend built with Next.js, including:
  - Server-Side Rendering (SSR)
  - Static Site Generation (SSG)
- MySQL database with Prisma ORM for secure data handling
- User authentication:
  - Login and registration
  - JWT token-based authentication
  - Password recovery with OTP
- Profile update functionality
- Commenting system for news posts
- Post search functionality
- Ability to browse and read news articles


## Tech Stack

- Frontend: HTML, CSS, Bootstrap, Next.js
- Backend: Next.js API Routes
- Database: MySQL
- ORM: Prisma
- Authentication: JWT tokens with custom login, registration, and OTP password recovery
